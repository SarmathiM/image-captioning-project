# Image Captioning AI

This is a simple AI-based web application that generates captions for images using computer vision and natural language processing.


## Technologies Used

* Python
* Flask
* TensorFlow / Keras
* NumPy
* Pillow
* gTTS


## Algorithm Used

* CNN (ResNet50) for feature extraction
* RNN / Deep Learning model for caption generation
* Text-to-Speech (gTTS) for audio output



## Features

* Image Upload
* Image Preview
* Caption Generation
* Voice Output
* Dark Mode
* Loading Indicator



## How to Run

Install dependencies:
pip install -r requirements.txt

Run application:
python app.py

Open browser:
http://127.0.0.1:5000/
